從外面看這台相機

ひとめぐり　星空教本

第一章
一顆星

整本教本只養一個場景。這一章從全黑開始，結束時畫面上會有一顆會轉的星，而你會知道它是怎麼被畫出來的。

旁邊那塊黑色不是還沒載入。它就是起點。

往下捲 ↓

01　SCENE

場景是一個空的容器

3D 畫面裡的所有東西，都要先被放進一個場景。它本身看不見，只是一個有座標的空間。

// 空間有了，但裡面什麼都沒有
const scene = new THREE.Scene();

為了看得見這個空間，先放一張格線當地板，再放三條軸線：紅色是 X（左右），綠色是 Y（上下），藍色是 Z（前後）。

格線和軸線是鷹架，成品裡不會有。但學的時候沒有它們，你分不出東西是變大了還是變近了。

02　MESH

放進第一顆星

一個看得見的物體由兩樣東西組成：形狀（幾何）和表面（材質）。兩者合起來叫 mesh，加進場景才會出現。

const shape   = new THREE.IcosahedronGeometry(1, 1);
const surface = new THREE.MeshBasicMaterial({ color: 0xecdcae });
const star    = new THREE.Mesh(shape, surface);
scene.add(star);

現在它是一顆由三角形拼成的多面體，表面只有一個平平的顏色，沒有明暗。線條是我特地畫上去的，不然你看不出它在轉。

它還不像星星。質感是下一章的事，這一章先確定它「在那裡」。

03　CAMERA

你看到的，是相機看到的

場景本身沒有「畫面」。畫面來自一台相機：它站在哪裡、看向哪裡、視角多寬，決定了一切。

右下角的小視窗是從外面看這台相機。那個錐形就是它看得到的範圍，錐形以外的東西不會被畫出來。

const camera = new THREE.PerspectiveCamera(
  50,      // 視角（度）
  aspect,  // 畫面長寬比
  0.5, 14  // 最近與最遠看得到的距離
);
camera.position.z = 6.0;
50°
6.0

按那三顆按鈕比較看看。星星在畫面上差不多一樣大，但感覺完全不同：廣角貼近時格線急速往遠方收，有壓迫感；長焦遠拍時格線幾乎平行，畫面安靜而扁平。

這就是為什麼「放大」有兩種做法，而它們不是同一件事。

04　RENDER LOOP

動畫是一張一張畫出來的

相機不會自己錄影。每一幀都是程式重新做一次三件事：把東西挪一點點、叫相機拍一張、等下一次輪到自己。

function tick() {
  star.rotation.y += 0.01;         // 1. 挪一點
  renderer.render(scene, camera);  // 2. 拍一張
  requestAnimationFrame(tick);     // 3. 排下一張
}
60
0

把幀數拉到 5 以下，星星會變成一格一格跳。它轉的速度沒有變，只是你看到的張數變少了。暫停之後連那個數字都會停，因為根本沒有人在畫。

之後所有會動的東西，包括捲動運鏡和粒子，都是在這個迴圈裡做的。

05　怎麼說

這一章給你的詞彙

鷹架拆掉了，剩下一顆星。以後跟模型或設計師描述畫面時，這些詞現在有了對應的畫面：

廣角／長焦
視角的寬窄。廣角誇張、有臨場感；長焦壓縮、安靜。
透視感
遠近物體的大小落差。貼近加廣角會變強，退遠加長焦會變弱。
近裁面／遠裁面
相機看得到的最近與最遠距離。東西莫名消失，通常是跑到這個範圍外了。
幀率
每秒畫幾張。順不順是它決定的，快不快不是。

所以同一個需求，可以從模糊變成精確：

✕　「星星大一點、有氣勢一點。」
○　「相機貼近到距離 3 左右，視角開到 80 度以上，讓星星佔畫面一半，邊緣帶一點廣角變形。」
