# ひとめぐり 星空教本

一個遞增式的 three.js 學習網站：同一個場景從全黑開始，每一章加入一個概念，最後是一件完成的作品。

**線上版**：https://yo02741.github.io/threejs-one-scene/

目標不是背程式碼，而是建立 3D 前端的直覺，並學會用精確的詞彙描述想要的畫面。每一章都可以轉旋鈕、看數值即時換成一句話，章末有「照著描述調出來」的練習。

```bash
npm install
npm run dev
```

- 專案說明、架構、目前進度：[`HANDOFF.md`](HANDOFF.md)
- 各章的規劃：[`PLAN.md`](PLAN.md)
- 模型來源與授權：[`public/models/README.md`](public/models/README.md)
