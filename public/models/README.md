# 模型來源

選修章用的兩個模型，都來自 Khronos Group 的 glTF Sample Assets，授權皆為 **CC0 1.0**（公眾領域，可自由使用）。

| 資料夾 | 模型 | 來源 |
|---|---|---|
| `lantern/` | Lantern（提燈） | https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Lantern |
| `avocado/` | Avocado（酪梨） | https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Avocado |

和原檔的差別：貼圖從 2048×2048 的 PNG 縮成 512×512 的 JPEG（原檔每個模型 8～9 MB，縮完各約 0.4 MB），`.gltf` 裡的貼圖檔名跟著改。幾何沒有動。
