ひとめぐり　星空教本

第四章
有重量的動作

星星現在只會一件事：用固定的速度轉。這一章結束時，它的出場、漂浮、被戳一下的反應，都會像一個有重量的東西。

這一章沒有新的物件。加進來的全部是「時間」。

01　EASING

同樣的時間，不同的走法

按「重播出場」，然後換一條曲線再按一次。四條都試試看。

const t = 經過的時間 / ;   // 0 → 1
const k = (t);         // 曲線在這一行
star.scale.setScalar(k);

圖的橫軸是時間，縱軸是「完成了多少」。四條線的起點、終點、花的時間都一樣，差別只在中間怎麼走。這條線叫緩動曲線。緩出是一開始快、最後慢下來；緩入相反。

「快」和「慢」多半不是速度的問題。同樣 0.9 秒，緩出感覺俐落，緩入感覺遲鈍，等速感覺像機器。

東西出現用緩出，離開用緩入，在畫面裡移動用緩入緩出。這條經驗法則能解決大半的情況。

02　SPRING

不問幾秒到，只問多硬多黏

連續快速地按「戳一下」（也可以直接點舞台上的星星）。然後切到「緩動」，再連按一次。

速度 += (- * 位移 -  * 速度) * dt;
位移 += 速度 * dt;
star.scale.setScalar(1 + 位移);

彈簧是另一種動法。它不規定幾秒走完，只規定兩件事：剛性（離目標越遠，拉回來的力越大）和阻尼（動得越快，煞車越用力）。阻尼小，就會衝過頭再彈回來，這叫過衝。

連按的時候差別就出來了。彈簧每戳一下都接在原本的動作上；緩動只能從頭播，所以會跳一下。

會被使用者打斷的動作，幾乎都該用彈簧。照劇本走的動作，用緩動。

補充：GSAP 是什麼

之後看別人的專案，很常會看到 GSAP。它是網頁上最常用的動畫函式庫，寫起來像這樣：gsap.to(star.scale, { x: 1, duration: 0.9, ease: "power3.out" })。

它幫你管的，就是這一章的東西：時長、緩動曲線，還有多段動畫的先後順序。你在上一段手寫的三行，是它的核心。

這本書沒有用它，因為這裡要看的正是那三行。實際做專案時，動畫一多，用它會省很多事。

03　IDLE

沒人碰它的時候

先把「漂浮幅度」拉大看清楚它在做什麼，再慢慢拉回來，停在你幾乎看不出來的地方。

star.position.y =  * Math.sin(時間 * 2π / );

一個來回花的時間叫週期，來回的距離叫幅度。漂浮、呼吸（微微放大縮小）、自轉，是三個各自循環的動作。

勾選「同一個節拍」，星星會像節拍器一樣規律。取消勾選，三個動作的週期錯開，組合起來很久才重複一次，看起來就像活的。

好的待機動作幾乎看不見。拿掉它，畫面卻馬上變死。

04　怎麼說

這一章給你的詞彙

定下來的是：出場 0.9 秒、緩出、尾巴衝過頭一點點；之後 7 秒一個週期緩緩漂浮，自轉放慢一半；被點到時用彈簧彈一下。

緩入／緩出／緩入緩出
動作的開頭慢、結尾慢，或兩頭都慢。
時長
一段動作花幾秒。介面上的動作多半在 0.2 到 1 秒之間。
過衝
衝過目標再回來。一點點是活潑，太多是廉價。
彈性／阻尼
彈簧的兩個旋鈕：多硬、多黏。
週期／幅度
循環動作多久一次、動多遠。
錯開
讓幾個動作不要同時開始、不要同一個節拍。

同一個需求，從模糊到精確：

✕　「動得自然一點。」
○　「出場 0.9 秒，緩出，尾巴帶一點點過衝；之後 7 秒一個循環上下漂浮，幅度很小，幾乎察覺不到。」
