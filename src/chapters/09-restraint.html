ひとめぐり　星空教本

第九章
拿掉

這一章不加任何東西。結束時，畫面上的東西會變少，而它會是一件完成的作品。

為了有東西可以拿，前八章的效果現在全部開到了偏多的程度：泛光更強、景深打開、顆粒更重、星星更多。看起來很熱鬧。先記住這個畫面。

01　BUDGET

一幀只有 16.6 毫秒

左下角多了一張圖：每一條是一幀花的時間，橫線是 16.6 毫秒。左上角是目前的數字。把「像素比」從 2 換成 1，看數字怎麼變；再換「粒子倍率」比較。

像素比。你的螢幕是 ；高於這個數字的選項不會有差別。

renderer.setPixelRatio(Math.min(window.devicePixelRatio, ));

每秒 60 張，等於每一張只有 16.6 毫秒。超過了，畫面就會掉格。這個時間叫幀率預算，場景裡的每一樣東西都在花它。

像素比是「一個 CSS 像素實際用幾個螢幕像素畫」。手機常常是 3，也就是同樣大小的畫面要算九倍的像素。而且每一道後製都是「整張圖重算一次」，所以這個九倍還要再乘上後製的關數。

最貴的通常不是三角形數，是像素數。粒子多八倍沒什麼感覺，像素比多一級馬上有感。

02　SUBTRACT

一樣一樣關掉

八個開關，對應前面八章加進來的東西。一次關一個，每關一個就問自己：畫面有變差嗎？還是只是變得不一樣？

你會發現有幾樣關掉之後幾乎看不出差別，卻省下不少毫秒（景深是最明顯的一個：它讓場景多畫一遍）。也有幾樣一關掉，畫面就死了（漂浮通常是）。

「我的版本」是這本書最後留下來的組合，不是標準答案。

加效果很容易。知道哪一樣可以不要，才是判斷力。這種判斷只能靠關掉來練。

03　SPACE

留地方給別的東西

畫面已經換成克制的版本了。現在把「標題字」打開，再拉「主星位置」，把星星從正中央移開。

camera.lookAt( * 偏移量, 0, 0);  // 相機看向星星的右邊，星星就落在畫面左邊

這個場景最後是一個網站的開場，不是一件展示品。它上面會有標題、有按鈕、有人要讀的字。星星在正中央時，字沒有地方放；移到左邊三分之一，右邊就空出來了。那塊空叫留白，它是畫面的一部分。

再把背景星的密度拉到最高：字開始難讀了。一個畫面只能有一個焦點，其他東西的工作是不要搶。

做開場的時候，最重要的那個元素往往不在 3D 場景裡。

04　EVERY DEVICE

不是每個人都看得到同一個畫面

三顆按鈕，模擬三種你的裝置上不會發生的情況。

if (低階裝置)  { 像素比 = 1; 粒子減半; 關掉後製; }
if (matchMedia('(prefers-reduced-motion: reduce)').matches) { 停在一張靜態畫面; }
if (!WebGL)   { 顯示一張靜態的備援畫面; }

降級是替跑不動的裝置準備一個比較便宜的版本：東西少一點、解析度低一點，但還是同一個畫面。減少動態是使用者在系統裡開的設定，有些人看到大範圍的動畫會暈；尊重它的做法是停在一張好看的靜態畫面。最後，總有瀏覽器開不了 WebGL，這時候要有備援：一張圖、一個漸層，什麼都好，就是不能一片空白。

開場卡住或壞掉的時候，使用者看到的不是「3D 效果沒出來」，是「這個網站壞了」。

練習

反過來：照著描述調出來

兩段描述，把畫面調成那個樣子。調對了會打勾；卡住的話，下面會提示還差什麼。

05　怎麼說

這一章給你的詞彙

所有的鷹架都拆了，這次是永久的。留下來的是：一顆手摺般的星，偏在左邊；一圈緩慢流動的光暈；一條斜斜的星帶和幾十顆漂著的小星；只有主星在發光。

幀率預算
每一幀可以花的時間。60 fps 是 16.6 毫秒。
像素比
實際畫的像素倍數。效能最大的一支旋鈕。
留白
刻意空下來的地方。給字、給眼睛休息。
焦點
畫面裡最該被看到的那一個東西。只能有一個。
降級
替慢的裝置準備的便宜版本。
備援
完全不能跑的時候顯示的東西。

同一個需求，從模糊到精確：

✕　「再酷一點。」
○　「拿掉景深和顆粒，泛光只留主星。主星放在左邊三分之一，右邊留給標題。手機上像素比鎖 1.5、粒子減半；減少動態時停在一張靜態畫面。」

而你在這一章調出來的版本，換成話是這樣：

九章到這裡結束。你從一塊黑色開始，現在可以用精確的話描述這個畫面的每一個部分。把它從頭播一次。
