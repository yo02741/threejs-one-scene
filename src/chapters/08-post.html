ひとめぐり　星空教本

第八章
拍下來之後

到上一章為止，場景畫完就直接送上螢幕。這一章在中間插一道手續。結束時，畫面看起來會像是被鏡頭拍下來的，而不是被電腦算出來的。

這一章不動場景裡的任何東西。動的是「那張圖」。

01　PIPELINE

先拍下來，再加工

舞台中間多了一條線，可以左右拖。線的左邊是原圖，右邊是加工過的。為了看得出差別，這裡先放一個最簡單的加工：把顏色拿掉。

const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));  // 1. 把場景拍成一張圖
composer.addPass(黑白);                            // 2. 加工那張圖
composer.addPass(new OutputPass());               // 3. 送上螢幕

後製的意思是：場景不直接畫到螢幕上，而是先畫到一張看不見的圖上，然後一關一關地處理那張圖。每一關叫一個 pass，內容就是上一章學的片段著色器，只是這次它處理的是整張畫面。

後製看不到 3D。它拿到的只是一張平面的圖，不知道哪裡是星星、哪裡是背景，也不知道誰近誰遠。

所以後製裡的一切，都只能靠「這個像素是什麼顏色、多亮」來判斷。記住這件事，下一段會用到。

02　BLOOM

夠亮的地方會暈開

星星開始發光了。先把「主星亮度」拉回 0.1，光暈會消失。再慢慢拉上來。

composer.addPass(new UnrealBloomPass(尺寸, , , ));
star.material.emissiveIntensity = ;

泛光（bloom）模仿的是鏡頭和眼睛的一個毛病：太亮的東西會往外暈。它的做法是把畫面裡亮度超過閾值的像素挑出來、模糊、再疊回去。

注意它挑的是「亮度」，不是「物件」。想只讓主星發光，沒辦法在後製裡指定「這顆」，只能回到場景裡，把主星的自發光調到比其他所有東西都亮，亮到超過閾值。

亮度可以超過 1，螢幕卻顯示不了。色調映射負責把超出範圍的亮度壓回螢幕能顯示的範圍，同時保留層次。關掉它，亮部會糊成一片死白。

想讓誰發光，就把誰調亮。泛光只是照實反映。

03　LENS

鏡頭的不完美

三個開關各試一次。景深打開後，拉「焦點距離」，讓清楚的位置從近處的小星移到遠處。

composer.addPass(new BokehPass(scene, camera, { focus: , aperture:  }));
// 顆粒 、暗角 ：寫在最後一關的 shader 裡

景深是只有某個距離清楚、其他地方模糊。焦點是清楚的那個距離，光圈越大模糊得越厲害。顆粒是底片的雜點，暗角是畫面四個角落比較暗。三樣都是真實鏡頭的缺陷，而電腦算出來的畫面太乾淨，加一點缺陷反而可信。

景深是這裡唯一「看得到遠近」的後製。它作弊了：為了知道每個像素離相機多遠，它讓場景再多畫一次。

每一樣都要把整張圖重新算過。它們不是免費的，下一章會算這筆帳。

04　GRADE

最後一關：調色

先按三個預設比較，再自己拉。

color *= ;                              // 曝光
color = mix(灰階(color), color, );          // 飽和度
color = (color - 0.18) *  + 0.18;       // 對比

調色是對整張圖的顏色做最後調整。這一關是自己寫的，三行就是上一章的片段著色器：輸入是那張圖上這個像素的顏色，輸出是調過的顏色。第一段的「黑白」其實就是把這裡的飽和度設成 0。

「暗部偏藍、亮部偏暖」是電影最常見的配色，和第三章「暖主光配冷補光」是同一個道理，只是這次直接作用在整張圖上。

打光決定哪裡亮哪裡暗，調色決定亮的和暗的各是什麼顏色。兩者都是情緒的旋鈕。

補充：後製用什麼做

這一章用的是 three.js 內建的 EffectComposer：每個效果一個 pass，依序處理。好處是不用多裝東西，每一關在做什麼也看得很清楚。

另一個常見的選擇是 postprocessing 這個套件（React Three Fiber 的後製就是包它）。它會把多個效果合併成一關來算，效果一多時明顯比較快，內建的效果也比較齊。

兩邊的概念完全通用：都是「先拍下來，再一關一關加工」，泛光、景深、調色的旋鈕也是同一批名字。

05　怎麼說

這一章給你的詞彙

分割線拆了。定下來的是：只有主星和少數最亮的背景星會泛光；很淡的顆粒和暗角；暗部略偏藍、亮部略偏暖。景深沒有留下來。

後製／pass
對拍好的圖做加工；每一道加工是一個 pass。
泛光（bloom）
亮的地方往外暈開。
閾值
多亮才算「亮」。越高，會發光的東西越少。
色調映射
把過亮的部分壓回螢幕顯示得了的範圍。
景深／焦點／散景
只有一個距離清楚；清楚的距離；模糊掉的光點。
顆粒／暗角
底片的雜點；四角變暗。
調色
曝光、對比、飽和度，以及暗部亮部各偏什麼顏色。

同一個需求，從模糊到精確：

✕　「要有電影感。」
○　「只讓主星泛光：閾值高、半徑大、強度中等。加很淡的顆粒和暗角，暗部偏藍、亮部偏暖。不要景深。」
