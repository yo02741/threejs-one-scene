ひとめぐり　星空教本

第五章
捲動就是運鏡

到目前為止，捲動只做一件事：決定你在讀第幾段。這一章結束時，你的滾輪就是攝影機的軌道。

接下來幾段的後面都接著一條長長的空白，那是給相機走的路。調好旋鈕，然後慢慢往下捲。

01　PROGRESS

捲動是一個 0 到 1 的數字

往下捲，看程式碼裡的「進度」和舞台。然後往回捲。

const 進度 = 這一段捲了多少;   // 現在是 
camera.position.z = lerp(, , 進度);

把「這一段捲了多少」換算成 0 到 1 之間的進度，再用進度在兩個數字之間取值（這個動作叫 lerp，線性內插）。相機沿著視線前進後退，叫推軌。

捲動不是「觸發」動畫，是「拖曳」動畫。你隨時可以停、可以往回，所以畫面只能由進度決定：同一個進度，永遠是同一個畫面。

這就是為什麼捲動動畫裡不會有「播放」這個動作。沒有東西在播，是你在拖。

02　DAMPING

相機是用追的

先取消勾選「平滑跟隨」，用滑鼠滾輪一格一格地捲。再勾起來捲一次。

const 目標 = lerp(, , 進度);
// 每一幀只追上差距的一小部分
camera.position.z += (目標 - camera.position.z) * ;

滾輪給的捲動是一格一格的，直接對應的話相機會跟著一頓一頓。平滑跟隨的做法是：相機不直接跳到目標，而是每一幀只走差距的一小段。那個比例就是阻尼。數字越小越黏、越滑；太小的話，你停下來了它還在動。

阻尼 0.1 左右是常見的起點。它讓便宜的滑鼠捲起來像昂貴的觸控板。

03　PATH

沿一條線走，盯著一個點

右下角的小視窗又出現了。綠色的線是相機要走的路。調整旋鈕，看線怎麼變，然後往下捲。

const 角度 = lerp(0, , 進度);
camera.position.set(
  sin(角度) * 5.5, lerp(0.5, , 進度), cos(角度) * 5.5);
camera.lookAt(0, , 0);

相機繞著主角轉，叫環繞。它需要兩樣東西：一條路徑（相機在哪裡），和一個注視點（相機看哪裡）。把注視點往上移，星星就會落到畫面下方。

到這裡，相機的三種基本動作都出現了：第一章的變焦（改視角）、上一段的推軌（改距離）、這一段的環繞（改角度）。三者可以同時發生。

運鏡的描述，就是在說這三件事各自從多少變到多少。

04　SHOTS

每一段有自己的鏡位

按三個鏡位切換看看。然後把切換方式改成「硬切」再按一次。

const shots = [
  { pos: [0, 0.5, 5.2],      fov: 50 },  // 正面
  { pos: [3.0, -1.4, 2.4],   fov: 72 },  // 仰角貼近
  { pos: [-1.6, 4.6, 3.0],   fov: 34 },  // 俯瞰
];
moveCameraTo(shots[]);

一組「位置、注視點、視角」叫一個鏡位。從一個鏡位到下一個，可以硬切（直接跳過去），也可以過渡（滑過去）。

其實這本書從第二章開始就在這樣做：每一章開頭相機都悄悄換了位置。從現在起，它是一份明確的資料，每一段都可以指定自己的鏡位。

過渡讓人知道「我們還在同一個地方」，硬切讓人知道「換話題了」。兩個都是工具。

06　怎麼說

這一章給你的詞彙

路徑線和小視窗都拆了。定下來的是那個鏡頭，以及一套規則：每一段有自己的鏡位，段落之間用過渡。

推軌
相機本身前進或後退。透視會跟著變。
變焦
相機不動，改視角。透視不變，只是裁得更緊。
環繞
相機繞著主角轉，始終看著它。
注視點
相機看向的那個點。移動它，主角在畫面裡的位置就變了。
鏡位
一組位置、注視點、視角。
硬切／過渡
鏡位之間直接跳，或滑過去。
阻尼
相機追上目標的黏度。
拖曳式
動畫由捲動進度決定，可以隨時停、隨時倒退。

同一個需求，從模糊到精確：

✕　「捲下去的時候鏡頭動一下。」
○　「在這段捲動裡，相機從正面繞到右後方 120 度，同時推近到距離 3、略微升高；跟隨帶一點阻尼，段落之間用過渡，不要硬切。」
