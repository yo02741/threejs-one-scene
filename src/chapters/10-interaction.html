ひとめぐり　星空教本

第十章
它知道你在

成品做完了，但它是一段影片：不管你做什麼，它都照自己的劇本走。這一章讓它注意到你。結束時，游標移動、指到星星、掃過星群，畫面都會有回應。

這一章要用滑鼠。把游標移到舞台上再開始。

01　PARALLAX

游標也是一個數字

在舞台上慢慢移動游標，從左邊移到右邊。然後把「強度」拉到最大再移一次。

// 游標在畫面上的位置：最左 -1，最右 1
目標 = 游標.x * ;
camera.position.x += (目標 - camera.position.x) * 0.08;
camera.lookAt(主角);  // 位置挪了，但還是看著同一個點

第五章把捲動換算成一個 0 到 1 的數字。游標也一樣：它在畫面上的位置可以換算成 -1 到 1。把這個數字接到相機的位置上，相機就會跟著游標微微移動，近的東西動得多、遠的東西動得少。這個效果叫視差，它讓平面的螢幕突然有了深度。

注意第二行：又是阻尼。相機不是直接跳到目標，而是每一幀追上一小段。沒有它，畫面會跟著手的每一個小抖動晃。

視差要小。大到讓人注意到的時候，它就從「有深度」變成「畫面在晃」了。

02　RAYCAST · HOVER

射一條線進去問

把游標移到主星上，再移開。綠色的小點是游標「碰到」星星的位置。

游標現在指到：沒有東西

raycaster.setFromCamera(游標, camera);          // 從相機朝游標的方向射一條線
const hits = raycaster.intersectObject(star);   // 這條線碰到星星了嗎
star.scale.setScalar(hits.length ? 1 +  : 1);

畫面是平的，場景是立體的。游標只知道自己在螢幕的哪一個像素，不知道那個像素後面是什麼。要知道「指到誰」，得從相機的位置朝游標的方向射一條線進場景，看它先碰到哪個物體。這叫射線檢測（raycast）。

游標停在物體上叫懸停（hover）。懸停時給一點回應，使用者就知道「這個可以點」。放大和縮回都是緩緩過去的，和視差一樣是用追的，不會瞬間跳。

手機沒有游標，所以沒有懸停。任何「只有懸停才看得到」的東西，手機使用者永遠看不到。

03　FIELD

讓整片星群讓路

用游標掃過主星旁邊的那些小星。然後把「力道」拉到負的，再掃一次。

力道是正的：推開。負的：吸過來。

for (const 小星 of 小星們) {
  const 距離 = 小星到那條射線的距離;
  if (距離 < ) 小星.位置 += 遠離射線的方向 * ;
}

同一條射線還能做別的事。這裡不問「碰到誰」，而是問每一顆小星「你離這條線多遠」。夠近的就被推開，越近推得越遠。游標就像一根看不見的棍子伸進星群裡。

這種「一個位置影響周圍一片」的做法，是很多互動效果的骨架：被游標撥開的草、跟著手指流動的粒子、靠近會亮起來的格子。

互動是加分，不是門檻。沒有人碰它的時候，畫面也必須是完整的。

練習

反過來：照著描述調出來

兩段描述，把畫面調成那個樣子。調完記得把游標移到舞台上試試看。

04　怎麼說

這一章給你的詞彙

綠色的小點拆了。定下來的是：很輕的視差；游標指到主星時它微微放大；掃過小星時它們輕輕讓開。

視差
視角移動時，近的東西動得多、遠的動得少。
懸停
游標停在物體上。只有滑鼠有，觸控沒有。
射線檢測
從相機朝游標射一條線，找出它碰到的物體。
回饋
使用者做了動作之後，畫面給的回應。
影響範圍
一個位置能影響到多遠的東西。

同一個需求，從模糊到精確：

✕　「要有互動感。」
○　「相機跟著游標做很輕微的視差，帶阻尼。游標懸停在主星上時緩緩放大 8%。游標附近 1.6 單位內的小星會被輕輕推開。手機上這些都不做，畫面照常。」

成品現在會回應你了。再播一次，這次記得動一動游標。
