ひとめぐり　星空教本

第二章
摸得到的表面

上一章的星星是一張平平的色紙。這一章結束時，它會變成一顆摸得出表面的東西：有稜角、有霧面、自己帶一點微光。

相機先靠近一點，等一下要看的是表面。

01　FACES

圓的東西，其實不存在

把滑桿慢慢往右拉，看星星的輪廓。

const shape = new THREE.IcosahedronGeometry(1, );
// 現在是  個三角形

3D 裡的每個形狀都是三角形拼出來的。三角形的數量叫面數：越多越接近圓，也越花力氣畫。把線框（只畫三角形的邊）關掉再拉一次，你會發現自己其實分不太出 500 和 720。

面數是細緻和效能之間的第一個取捨。之後覺得「不夠圓」的時候，先問：需要多圓？

02　MATERIAL

換一種表面，然後它黑掉了

到目前為止，星星的材質只有一個顏色，有沒有光都一樣亮。按下 Standard，換成一種會回應光的材質。

const surface = new THREE.MeshStandardMaterial({ color: 0xecdcae });

全黑不是壞掉。Standard 材質描述的是「這個表面怎麼反光」，而場景裡還沒有任何光。現在把工作燈打開。

這盞燈是借來的。光是下一章的主題，這裡先借一盞固定的燈、加一個中性的攝影棚環境，讓表面有東西可以反應。

材質不是顏色，是表面對光的反應。沒有光，再好的材質也是黑的。

03　ROUGHNESS · METALNESS

兩個數字，決定它像什麼

這一段已經幫你換好材質、開好燈。先把四顆按鈕各按一次。

surface.roughness = ;
surface.metalness = ;

粗糙度是表面有多霧：0 像鏡子，1 像粉筆。金屬感是它算不算金屬：0 是塑膠、陶瓷這類東西，1 是金屬。金屬幾乎不顯示自己的底色，而是映出周圍的環境，所以拋光金屬的星星上看得到攝影棚的影子。

大部分「質感」的需求，講的其實都是這兩個數字。

04　SHADING

稜角是選出來的

打開「平面著色」，再關掉，來回幾次。三角形一個都沒有變。

surface.flatShading = ;

那些淺色的小箭頭叫法線，代表表面「朝向哪裡」，光影就是照它算的。平面著色時每個面只有一個朝向，面和面之間有明確的折線。平滑著色時朝向記在頂點上，在面的內部慢慢過渡，光影就連成一片。

所以「看起來圓滑」和「面數多」不是同一件事。把細分調到 1、關掉平面著色：只有 80 個面，看起來卻比 320 個面的平面著色還圓。

不過輪廓騙不了人。看星星的邊緣，它還是多邊形。

05　怎麼說

這一章給你的詞彙

旋鈕收起來了，線框也拆了。這是這一章定下來的樣子：低面數、保留稜角的霧面星，像手摺出來的，自己帶一點暖色的微光。工作燈還亮著，下一章再還。

面數／低面數
三角形的數量。低面數不是偷懶，可以是一種風格。
線框
只畫三角形的邊。用來檢查形狀，不是成品。
粗糙度
表面有多霧。越低越像鏡子。
金屬感
是不是金屬。金屬映出環境，非金屬顯示自己的顏色。
平面著色／平滑著色
要不要看到面和面之間的折線。和面數無關。
自發光
不靠光也看得到的顏色。很弱的自發光能讓暗面不會死黑。

同一個需求，從模糊到精確：

✕　「星星要有質感一點。」
○　「低面數、保留稜角，表面是不反光的霧面，粗糙度 0.4 到 0.5，不要金屬感，本身帶一點暖色的微光。」
