ひとめぐり　星空教本

第三章
光從哪裡來

上一章借了一盞工作燈。這一章把它還回去，換成三盞自己擺的燈。結束時，星星會有亮面、暗面，和一道被勾出來的邊。

先把工作燈關掉。剩下的那一點點亮，是星星自己的自發光。

01　KEY LIGHT

一盞燈，決定哪裡亮

現在場景裡有一盞你的燈了。先把「方位」從左拉到右，讓燈繞星星走一圈。

const key = new THREE.DirectionalLight(0xffffff, );
key.position.set(...);  // 方位 °、高度 °
scene.add(key);

這盞叫主光：畫面裡最主要的那盞燈，亮面和暗面的分界由它決定。舞台上的小球是它的位置，線指向星星。

再做一個實驗。把方位轉到 0（燈在相機正後方），強度拉到最大：很亮，但是平的。然後強度拉回 2.5，方位轉到 70：暗下來了，體積卻出來了。

光打在哪裡，比光有多亮重要。

02　THREE-POINT

三盞燈，各有工作

先按四顆按鈕比較，再自己開關每一盞。

scene.add(key);   // 主光：定出形狀
scene.add(fill);  // 補光：強度 ，救回暗面
scene.add(rim);   // 輪廓光：強度 ，從背後勾邊

補光放在主光的另一側，比主光弱，工作是讓暗面不要全黑。輪廓光放在物體背後，只照到邊緣，把它從背景裡切出來。

「平光」把補光開得和主光差不多亮：什麼都看得清楚，也什麼都不立體。主光和補光的強弱比例叫光比，比例越懸殊越戲劇。

「立體感」是亮和暗的比例，不是亮度。

03　COLOR TEMPERATURE

光有顏色

把主光往暖的方向拉，補光往冷的方向拉。

色溫：-1 是冷的藍白，0 是白，1 是暖的橘白。

key.color.set(暖白);    // 色溫 
fill.color.set(冷白);   // 色溫 
scene.add(new THREE.HemisphereLight(天空色, 地面色, ));

色溫講的是光偏暖還是偏冷。暖的主光配冷的補光是最常見的搭法：亮面像被太陽照到，暗面像映著天空。反過來配，就變成夜晚、月光。

環境光沒有方向，從四面八方均勻地來，把整體墊亮一點。開太多，辛苦擺出來的明暗就被沖平了。

色溫是調整畫面情緒最便宜的旋鈕：一行程式，不花任何效能。

04　SHADOW

影子要另外算

星星浮在太空裡，沒有東西可以接影子。這裡臨時放一塊地面。光打著、星星在、地面也在，但是沒有影子。把「投影」打開。

影子的解析度。先選 128 看看。

key.castShadow = ;         // 光同意
star.castShadow = true;        // 投影的物體同意
ground.receiveShadow = true;   // 接影子的表面同意
key.shadow.mapSize.set(, );

投影不是光附贈的。它的做法是：站在光的位置，把整個場景再拍一次，記下「光看得到哪裡」；看不到的地方就是影子。所以開一盞會投影的燈，場景就要多畫一遍。解析度選 128 時邊緣的鋸齒，就是那張圖太小的結果。

影子要光、物體、表面三方都同意，而且很貴。需要的時候才開。

05　怎麼說

這一章給你的詞彙

地面拆了，光源的標記也拆了。定下來的是：左上前方一盞暖白的主光，右邊一盞很弱的冷色補光，背後一道輪廓光。成品裡沒有地面，所以不投影；但星星自己身上的暗面留著。

主光／補光／輪廓光
定形、救暗部、勾邊。三盞燈三種工作。
光比
主光和補光的強弱比例。差越多越戲劇，越接近越平。
色溫
光偏暖或偏冷。暖主光配冷補光是白天，反過來是夜晚。
環境光
沒有方向的光，把整體墊亮。
亮面／暗面
物體自己身上受光和背光的部分。不需要投影也有。
投影
物體落在別的表面上的影子。要另外算，而且貴。

同一個需求，從模糊到精確：

✕　「打亮一點、立體一點。」
○　「主光從左上 45 度打，暖白色；補光只要主光的四分之一、偏冷；背後加一道輪廓光把邊緣勾出來。不需要投影。」
